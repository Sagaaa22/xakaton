# 🎮 Grand Mobile Support Copilot (Decentrathon 6.0)

> **ИИ-помощник службы поддержки и администрации Grand Mobile (GTA RP / CRMP)**  
> Проект автоматически читает обращения игроков, понимает язык (`RU`, `KZ`, `UZ`, `EN`), определяет категорию и срочность, находит точные статьи из `rules.json` и готовит вежливый готовый ответ для администратора.

---

## 👶 Как запустить проект (Супер-простая инструкция для новичков)

Если вы никогда не запускали подобные проекты — не переживайте! Просто повторяйте действия по шагам ниже.

---

### Шаг 1. Откройте терминал (консоль)
1. Откройте папку с проектом на компьютере.
2. Зажмите клавишу `Shift` на клавиатуре и нажмите **правой кнопкой мыши** в свободное место папки.
3. Выберите пункт **«Открыть окно PowerShell здесь»** (или «Открыть в Терминале»).

---

### Шаг 2. Установите необходимые библиотеки (делается 1 раз)
Скопируйте эту команду, вставьте в окно терминала и нажмите `Enter`:

```powershell
pip install -r requirements.txt
```
*Подождите 30–60 секунд, пока компьютер скачает всё необходимое.*

---

### Шаг 3. Запустите сервер одной командой

#### На Windows:
```powershell
.\make.bat run
```
*(Или универсальная команда: `python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`)*

#### На Linux / macOS:
```bash
make run
```

Когда сервер запустился, в окне появится надпись:
```text
INFO:     Application startup complete.
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
```
🎉 **Готово! Сервер работает! Не закрывайте это черное окно.**

> 💡 **Что делать, если пишет ошибку `[WinError 10048] порт 8000 уже занят`?**  
> Это значит, что сервер уже работает в другом окне. Чтобы освободить порт, введите команду:  
> `taskkill /IM python.exe /F` и запустите снова.

### 🕹️ Сценарий для проверки («Куда нажимать в интерфейсе»):

1. **Зайдите на сайт**: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
2. Вверху справа переключатель ролей: **Junior Admin (Младший)** и **Senior Admin (Старший)**.
3. Нажмите на любой тикет из списка слева.
4. Нажмите синюю кнопку **«Взять в работу»** — вы увидите:
   - Определенную ИИ категорию и срочность (например, `p0 - Критично` или `p2 - Обычный`).
   - Подтвержденные пункты из базы правил (например, `п. 2.1` или `GZ 1.1`).
   - Готовый черновик ответа игроку.
   - Если в тикете жалоба на читы или ДМ, кнопка «Отправить» будет заблокирована правилом безопасности (**`needs_human: true`** — ИИ не может наказывать сам).
5. Нажмите **«Передать старшему специалисту»** и напишите причину.
6. Переключите тумблер вверху на **Senior Admin** — старший увидит уведомление, историю передачи и нажмет **«Одобрить решение»**. Всё сохраняется в истории!
7. Перейдите во вкладку **AI Assistant** в левом меню, напишите: `Где сдать на права?` и нажмите кнопку — ИИ выдаст точный маршрут к автошколе в Батырево и команды `/gps`!

### Шаг 5. Как запустить тесты и предсказания из ТЗ хакатона

#### 1. Запуск всех 17 автотестов:
```powershell
.\make.bat test
```
*(На Linux: `make test`). Все 17 тестов пройдут с вердиктом `OK`.*

#### 2. Пакетная обработка файла с тикетами (`make predict`):
```powershell
.\make.bat predict IN=tickets_valid.jsonl OUT=pred.jsonl
```
*(На Linux: `make predict IN=tickets_valid.jsonl OUT=pred.jsonl`)*.  
Команда обработает 1000 тикетов и выведет точность (86%), F1-меру (0.895), скорость (10.9 мс) и нулевую стоимость ($0.00).

## 🏆 Техническое описание для жюри и разработчиков

### 1. Соответствие официальным правилам и ТЗ
- **База правил (`rules.json`)**: 11 официальных разделов Grand Mobile (198 статей и RP-терминов).
- **Таксономия (`taxonomy.json`)**: 14 официальных категорий (`complaint.insult`, `complaint.cheat`, `complaint.dm`, `complaint.scam`, `complaint.rmt_ads`, `complaint.admin`, `complaint.other`, `complaint.invalid`, `report.question`, `report.help`, `report.complaint`, `report.account`, `report.payment`, `report.offtopic`), 4 приоритета (`p0`–`p3`).
- **Безопасность (`SafetyGuard`)**: Защита от обещания разбана, возврата средств или самовольного наказания игрока без участия модератора.
- **Поддержка языков**: Автоматическое распознавание и качественные ответы на `Русском`, `Казахском`, `Узбекском` и `Английском` языках.

### 3. Запуск через Docker

Если у вас установлен Docker, можно запустить всё одной командой:
```bash
docker compose up --build
```
Сервис поднимется в изолированном контейнере и будет доступен по адресу `http://localhost:8000/`.

### 4. Структура файлов проекта
- `app/main.py` — веб-сервер FastAPI, эндпоинты `/triage`, `/health`, статика UI;
- `app/triage.py` — главный мозг системы: триаж, логика `needs_human`, расчет метрик;
- `app/generator.py` — генератор ответов: база игровых команд Grand Mobile + регламент наказаний;
- `app/rag.py` — быстрый гибридный поиск по 198 статьям `rules.json` (BM25 + n-граммы + термины RP);
- `app/classifier.py` — классификатор категорий и приоритетов на основе `taxonomy.json`;
- `app/extractor.py` — извлечение фактов: никнеймы, сервер, суммы, команды (`/time`, `/gps`), язык;
- `app/safety.py` — фильтр безопасности `SafetyGuard`, предотвращающий ложные обещания;
- `app/workspace.py` — движок ролевого доступа RBAC (Junior / Senior Admin), аудит-лог и эскалация;
- `app/static/index.html` — SPA-интерфейс панели оператора с тёмной темой Grand Mobile;
- `tests/test_triage.py` — 17 модульных и интеграционных тестов;
- `REPORT.md` — подробный финальный отчет с графиками, метриками и замерами скорости.
